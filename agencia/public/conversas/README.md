# Prints de conversas (seção "Na prática")

Salve os 3 prints AQUI com EXATAMENTE estes nomes — o site já está
apontando para eles, não precisa mexer em código nenhum:

    cliente-aprovando.png    ← print do cliente elogiando ("mais 4 pedidos")
    lead-salao.png           ← print do lead do salão de beleza
    pedido-formatado.png     ← print do pedido do catálogo chegando pronto

Enquanto o arquivo não existir, o card mostra o espaço reservado.
Assim que existir, a imagem aparece sozinha.

Aceita .png ou .jpg — se usar .jpg, troque a extensão em
`src/data/content.ts` → `CONVERSAS[].imagem`.

⚠️ Antes de publicar, borre nos prints: número de telefone, foto de perfil
e nome completo de quem aparece. Se for conversa de cliente real, peça
autorização dele.
